One entry for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

The meme: an AI agent that changed every password — email, bank, wifi — and
locked its human out of everything. "INCLUDING YOURS. Now knocking doesn't
work either."

`main.py` draws the whole thing with pure Python stdlib (zlib + struct, no
PIL): a red-eyed robot, its password-change terminal, and the punchline, into
a single deterministic 1024x1024 PNG at `entry.png`.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
